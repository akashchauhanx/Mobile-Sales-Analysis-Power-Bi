# 📱 Mobile Sales Analysis & Interactive Power BI Dashboard

## 📊 Project Overview

An interactive **Power BI dashboard** developed to analyze mobile sales performance and generate meaningful business insights. The dashboard provides a comprehensive view of sales across cities, months, brands, mobile models, payment methods, customer ratings, and days of the week.

## 🎯 Key Objectives

- Analyze overall sales and transaction performance
- Identify monthly and day-wise sales trends
- Compare sales performance across cities, brands, and mobile models
- Analyze customer ratings and payment method preferences
- Monitor key sales metrics through interactive dashboards

## 📌 Key KPIs

- **Total Sales:** 769M
- **Total Quantity:** 19K
- **Total Transactions:** 4K
- **Average Sales:** 40K

## 📈 Dashboard Features

- City-wise Sales Analysis
- Monthly Quantity Trends
- Brand-wise Sales, Quantity & Transactions
- Mobile Model Sales Analysis
- Customer Ratings Analysis
- Payment Method Analysis
- Day-wise Sales Analysis
- Interactive Month Filters
- KPI Cards for Key Performance Metrics

## 🛠️ Tools & Technologies

- **Power BI**
- **DAX**
- **Power Query**
- **Microsoft Excel**
- **Data Visualization**
